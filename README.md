# Exercice 1 : Gestion d'un Compte Bancaire

Cet exercice consiste à créer une classe CompteBancaire en C++ pour gérer un compte bancaire. Il permet de manipuler le constructeur paramétré, le constructeur de copie, le constructeur de déplacement et le destructeur. La classe permet également d'effectuer des dépôts, des retraits et de conserver un historique des opérations.

# Exercice 2 : Gestion d'un Buffer Dynamique

Cet exercice consiste à créer une classe Buffer en C++ pour gérer une zone mémoire dynamique. Il permet de manipuler l'allocation et la libération de mémoire, le constructeur de copie, le constructeur de déplacement, ainsi que les opérateurs d'affectation par copie et par déplacement.

# Exercice 3 : Constructeur avec Liste d'Initialisation

Cet exercice consiste à créer une classe Point3D en C++ contenant trois membres constants (x, y et z). Il permet d'utiliser les listes d'initialisation dans le constructeur et de comprendre pourquoi elles sont obligatoires pour initialiser les membres constants. La classe contient également des accesseurs et une méthode d'affichage des coordonnées.
